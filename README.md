# trackleadflow-web

Contrato de pastas do painel Angular. O cliente do anúncio conversa pelo WhatsApp oficial. Este repositório é o painel do Admin e do Especialista: a conexão da Cloud API e a conexão do anúncio são telas daqui, cada uma falando com o módulo dono.

Ainda não há projeto Angular gerado, de propósito: a árvore separa componentes genéricos e páginas sem código de implementação.

A regra de burro/inteligente e o mapa de páginas estão em [docs/arquitetura.md](docs/arquitetura.md).
